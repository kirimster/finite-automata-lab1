# Практическая работа №1. Конечные автоматы

## Описание

Данная программа реализует **детерминированный (ДКА)** и **недетерминированный (НКА)** конечные автоматы на языке Python.

**Задача «а» (ДКА):**
Построить ДКА, допускающий в алфавите `{0, 1}` все цепочки, в которых **перед каждой единицей находится либо 0, либо ровно 2 нуля**. Завершающие нули не важны.

**Задача «б» (НКА):**
Построить НКА, допускающий цепочки в алфавите `{0, 1}`, в которых **содержится два нуля, разделённых позициями в количестве, кратном 4**. Примечание: нуль тоже кратен 4.

---

## Требования

- **Python 3.6+**
- Любая среда разработки: PyCharm, VS Code, или запуск из командной строки.

---

## Как запустить

### Вариант 1: PyCharm

1. Откройте проект в PyCharm.
2. Найдите файл `dfa_task.py` (для ДКА) или `nfa_task.py` (для НКА).
3. Нажмите **Shift+F10** или правой кнопкой → **Run**.
4. В консоли введите строку и нажмите **Enter**.
5. Программа выведет `Accepted` или `Rejected`.
6. Для выхода введите пустую строку и нажмите **Enter**.

### Вариант 2: Командная строка

```bash
python dfa_task.py
```

или

bash

```
python nfa_task.py
```

## Как пользоваться

### ДКА (задача «а»)

После запуска программа выведет:

text

```
=== ДКА: перед каждой единицей 0 или ровно 2 нуля ===
(введите пустую строку для выхода)
Строка:
```

Введите строку из символов `0` и `1`, например:

text

```
Строка: 001000
```

Программа выведет пошаговый переход и результат:

text

```
  Начальное состояние: q0
  Прочитан '0' -> q1
  Прочитан '0' -> q2
  Прочитан '1' -> q0
  Прочитан '0' -> q1
  Прочитан '0' -> q2
  Прочитан '0' -> q3
  Результат: Accepted
```

### НКА (задача «б»)

После запуска программа выведет:

text

```
=== НКА: два нуля на расстоянии, кратном 4 ===
(введите пустую строку для выхода)
Строка:
```

Введите строку из символов `0` и `1`, например:

text

```
Строка: 011110
```

Программа выведет пошаговое изменение множества состояний и результат:

text

```
  Начальное множество: { Q0 }
  Прочитан '0' -> { A0, Q0 }
  Прочитан '1' -> { A1, Q0 }
  Прочитан '1' -> { A2, Q0 }
  Прочитан '1' -> { A3, Q0 }
  Прочитан '1' -> { A0, Q0 }
  Прочитан '0' -> { A0, Q0, QF }
  Результат: Accepted
```
